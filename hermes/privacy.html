Hermes Privacy Policy

Last updated: November 13, 2026

Hermes is a private assistant used only by its owner. It is not available to the public.

Data accessed

With the owner's explicit consent, Hermes accesses the owner's Google Calendar, Gmail and Google Drive only to carry out the owner's own requests (for example reading the schedule, organizing mail, or filing documents).

Use and storage

Google user data is used solely to provide these features to the owner. It is stored only on infrastructure controlled by the owner, is not sold, is not shared with third parties, is not used for advertising, and is not used to train generalized AI or machine-learning models.

Hermes's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/connections.
